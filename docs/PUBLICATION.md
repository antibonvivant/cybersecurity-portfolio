# Publication and completion gates
- Keep unredacted originals in evidence-private outside tracked content.
- Publish sanitized XML/CSV excerpts and screenshots only after checking usernames, hostnames, IPs, e-mail addresses, tokens and client details.
- Keep original and redacted hashes separate; redaction changes the file hash.
- For public samples: record source, download date, license/terms and hash. Link to the sample rather than redistributing without permission.
- Do not paste credentials or authentication cookies.
- Verify local relative links and commands.
- Candidate must run and explain the tools; AI preparation is disclosed.
- Completed means: executed steps, artifacts, timeline, actual query, findings, alternative explanations, limitations, reviewed report and independent explanation by candidate.
- Completion of XML/local log analysis is not completion of Wazuh integration. Record each capability separately.
